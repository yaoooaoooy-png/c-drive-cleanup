导入清单
拖 JSON 文件到这里，或 点击选择文件

页面只认一个 JSON 对象。除 items 外都可省略。

字段说明必填
title清单标题
generatedAt生成日期，如 2026-10-28
disk{ total, used, free }，单位 GB；不填则汇总条只显示已选量
items[]候选项目数组必填
items[].id编号，如 A1。回执用它，必须唯一必填
items[].name显示名必填
items[].gb体积，GB，数字必填
items[].path完整路径
items[].group分组字母，如 A / B / C。不填取 id 首个字母
items[].risk1 低 / 2 中 / 3 高
items[].files文件数，仅显示
items[].ext扩展名统计结论
items[].backupnone / rename / copy，回滚点状态
items[].irreversibletrue 表示删除后无法恢复，行内标红
items[].note备注，悬停显示

最小示例

{
  "title": "C 盘清理 · 第 3 轮",
  "generatedAt": "2026-10-28",
  "disk": { "total": 120, "used": 107.59, "free": 12.41 },
  "items": [
    {
      "id": "A1",
      "name": "Windows 更新缓存",
      "gb": 9.78,
      "path": "C:\\\\Windows\\\\SoftwareDistribution\\\\Download",
      "group": "A",
      "risk": 1,
      "files": 531619,
      "ext": "缓存文件为主，无用户文档",
      "backup": "none"
    }
  ]
}

JSON 里的反斜杠要写两个。最省事的做法：先导入，改完再导出。
